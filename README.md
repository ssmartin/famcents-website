# getourcents.app

The website for OurCents, the private expense tracker for couples: homepage, privacy policy, support and terms.
Plain HTML and CSS, no build step; deployed with Cloudflare Workers on getourcents.app.

| Page | URL | File |
|---|---|---|
| Homepage | https://getourcents.app/ | `index.html` |
| Privacy policy | https://getourcents.app/privacy | `privacy/index.html` |
| Support | https://getourcents.app/support | `support/index.html` |
| Home and privacy policy in German, Romanian, Spanish | https://getourcents.app/de/ and /de/privacy (ro, es) | `de/index.html`, `de/privacy/index.html` (`ro/`, `es/`) — the English privacy policy is the binding one (note at the top of each translation); change all four together |
| Support in German, Romanian, Spanish | https://getourcents.app/de/support (ro, es) | `de/support/index.html` (`ro/`, `es/`) — the app opens the one in its language; keep them in step with the English page and use the app's own labels (`src/locales/<language>` in the app repository) |
| Terms | https://getourcents.app/terms | `terms/index.html` |

## Before launch

- Support email on every page: **smartin.appsupport@gmail.com**.
- [ ] **Terms**: fill in the developer name and address and the effective date; have the terms reviewed.
- [ ] **Privacy policy**: keep the text in sync with the app (`src/lib/legal.ts` and `docs/privacy-policy.md` in
      the OurCents repository) and update the effective date.
- Screenshots in `assets/screenshots/` are generated with sample data (see `store-assets/README.md` in the app
  repository); replace them with phone screenshots when available.
- [ ] **Store links**: replace the "Coming soon" buttons with the official App Store / Google Play badges and links.
- Icons (`assets/favicon.png`, `apple-touch-icon.png`, `icon-512.png`) are generated by `scripts/make-icons.ps1` in the
  OurCents app repository (`-WebDir`).

## Hosting

The site is deployed with **Cloudflare Workers** on getourcents.app (set up in the Cloudflare dashboard). If the
Worker is connected to this repository, pushing to `main` publishes the changes; otherwise redeploy from Cloudflare.

## Preview locally

Open `index.html` in a browser, or run a small server so the `/privacy/`-style links work:

```bash
npx serve .
```
